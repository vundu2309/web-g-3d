# Work records

One Markdown file per change that goes through the [agent workflow](../agent-workflow.md), named `YYYY-MM-DD-short-name.md` and started from [`_template.md`](_template.md). The record is the single place that says what the change is, who builds it, what evidence exists, what the user approved and which commits published it; lasting decisions go to `docs/decisions/`. Keep it short and current: change `state` in the front matter when a gate is passed, and never before.
