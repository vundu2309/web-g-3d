# Phạm vi wiki

Viết tiếng Việt, giữ nguyên tên API và lệnh. Tài liệu phục vụ phát triển game Hải trình: vòng đời Babylon, trường sóng dùng chung CPU/GPU, render nước, ranh giới Havok, kiểm tra và deploy Pages. Dẫn nguồn từ code/test/workflow. Phân biệt mô phỏng nổi bằng toán với lực nổi vật lý thật, và phân biệt bài test chạy trong cloud với các bước thực sự chạy trong CI. Không mô tả chất lượng hình ảnh hoặc FPS đã được đảm bảo. Không đọc hoặc chép credential. Không sửa source khi cập nhật wiki.
